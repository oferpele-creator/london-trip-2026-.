# London · trip plan (20–24.11.2026)

אפליקציית ווב לתכנון הטיול ללונדון, מותאמת לנייד. כתובה ב-HTML, CSS ו-JavaScript פשוטים, בלי שלב build, ויש בה פונקציית שרת אחת (`api/ask.js`) שמחברת את כפתור "שאל" ל-Claude.

## מה יש בפנים
- **ציר זמן**: טאב לכל יום עם אייקון מזג אוויר (Open-Meteo), תחנות עם שעה, תמונה, קטגוריה, זמן נסיעה ו"לצאת ב-". יום החוץ משובץ אוטומטית ביום הכי שמשי מבין 22 ו-23/11, ויש כפתור להחלפה ידנית.
- **מפה**: Leaflet ו-OpenStreetMap, נעצים ממוספרים לפי יום וסינון לפי יום או רשימת משאלות.
- **מקומות**: חיפוש, סינון לפי קטגוריה ו"קרוב אליי": מיון לפי מרחק הליכה, ורק מקומות שפתוחים עכשיו.
- **דף מקום**: תמונה מ-Wikimedia Commons עם קרדיט, שעות פתיחה ותג "פתוח עכשיו", תחנה קרובה, רכבות בזמן אמת ומצב הקווים (TfL), מפה קטנה וניווט, ותמונות והערות אישיות. למסעדות ולברים יש דף משלהם.
- **הוצאות**: מי שילם על מה בפאונד, המרה לשקלים בשער עדכני ומי חייב למי.
- **מידע**: טיסות, הסעה, לינה, איך מתניידים, מצב כל הקווים, התראות יציאה, ייצוא ליומן (`.ics`) ורשימת ציוד.
- **דף סיכום**: כל ההערות, התמונות וההוצאות, עם אפשרות להדפיס או לשמור כ-PDF.
- עברית ואנגלית, מצב כהה (אוטומטי או ידני), ועבודה בלי אינטרנט לאחר הטעינה הראשונה (service worker).

כל מה שלא אומת מסומן באפליקציה בתג **"לא אומת"** או **"אומת חלקית"**. התוכן כולו נמצא בקובץ `js/data.js`, ואפשר לערוך אותו ישירות.

הבית: **6 Park Avenue, London N3 2EJ** (פינצ'לי), כבר מוגדר באפליקציה.

## העלאה לאוויר: צעד אחרי צעד (בלי טרמינל)

### חלק א׳: GitHub (איפה שהקוד נשמר)
1. נכנסים ל-github.com ונרשמים, או מתחברים אם כבר יש חשבון.
2. לוחצים על **+** למעלה ← **New repository**.
3. בשדה Repository name כותבים `london-trip`, ומסמנים **Private**. לא מסמנים שום דבר אחר (בלי README) ← **Create repository**.
4. בעמוד שנפתח לוחצים על הקישור **uploading an existing file**.
5. פותחים במחשב את הקובץ `london-trip.zip`, נכנסים לתיקייה `london-trip`, מסמנים **את כל מה שבתוכה** (תיקיות וקבצים) וגוררים לחלון של GitHub.
6. מחכים שכל הקבצים יעלו ולוחצים **Commit changes**.
7. בודקים שבעמוד הראשי של הריפו רואים ישירות את `index.html`, `api`, `js` וכו׳, ולא תיקייה אחת בשם `london-trip`.

### חלק ב׳: מפתח Claude API
1. נכנסים ל-console.anthropic.com ונרשמים.
2. ב-**Billing** מוסיפים קרדיט, למשל 5$. החיוב על ה-API נפרד מהמנוי ל-Claude.ai, ושאלה אחת עולה בערך סנט אחד.
3. ב-**API Keys** לוחצים **Create Key** ומעתיקים את המפתח (מתחיל ב-`sk-ant-`). המפתח מוצג פעם אחת בלבד.

### חלק ג׳: Vercel (מה שמעלה את האתר לאוויר)
1. נכנסים ל-vercel.com ← **Sign Up** ← **Continue with GitHub**, ובוחרים בתוכנית **Hobby** החינמית.
2. לוחצים **Add New… → Project**. אם הריפו לא מופיע: **Adjust GitHub App Permissions** ← נותנים גישה ל-`london-trip`.
3. לוחצים **Import** ליד `london-trip`.
4. Framework Preset: **Other**. לא נוגעים ב-Build Command או ב-Output Directory.
5. פותחים את **Environment Variables** ומוסיפים:
   - Key: `ANTHROPIC_API_KEY`
   - Value: המפתח מחלק ב׳
6. לוחצים **Deploy**. אחרי בערך דקה מקבלים כתובת כמו `london-trip-xxxx.vercel.app`.
7. מעכשיו, כל שינוי שעולה ל-GitHub מעדכן את האתר אוטומטית.

> שכחתם את המפתח בשלב 5? נכנסים ל-Settings ← Environment Variables, מוסיפים אותו, ואז Deployments ← ⋯ ← **Redeploy**.

### חלק ד׳: בטלפון
- פותחים את הכתובת ב-Safari באייפון, או ב-Chrome באנדרואיד ← **שיתוף ← הוספה למסך הבית**.
- כשהאפליקציה מבקשת הרשאת מיקום ("קרוב אליי", "שאל") או הרשאת התראות, מאשרים.
- התראות היציאה עובדות כשהאפליקציה פתוחה או ברקע. באייפון צריך קודם להוסיף אותה למסך הבית (iOS 16.4 ומעלה).

### לשולטים בטרמינל (במקום חלק א׳)
```bash
cd london-trip
gh repo create london-trip --private --source=. --push
```

### מודל
ברירת המחדל היא `claude-sonnet-5-5`. אפשר להגדיר ב-Vercel את המשתנה `CLAUDE_MODEL=claude-haiku-5-5`, שהוא זול ומהיר יותר.

## הרצה מקומית
```bash
python3 -m http.server 8000      # הכל עובד, חוץ מכפתור "שאל"
npx vercel dev                   # כולל גם את /api/ask (צריך ANTHROPIC_API_KEY בקובץ .env)
```

## מקורות נתונים (בלי מפתחות API)
Open-Meteo (מזג אוויר) · TfL Unified API (רכבות ומצב קווים) · OpenStreetMap ו-Nominatim (מפה ומיקוד) · Wikimedia Commons (תמונות, עם קרדיט לכל תמונה) · open.er-api.com (שער ליש״ט/ש״ח).
Leaflet ופונטים Rubik ו-Silkscreen (רישיון OFL) נמצאים מקומית בתיקיות `vendor/` ו-`fonts/`.
